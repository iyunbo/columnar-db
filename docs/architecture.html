Architecture

Five layers, bottom to top. Each layer only depends on the one below it.

Query Pipeline

SELECT city, COUNT(*), AVG(age)
FROM people WHERE age > 30
GROUP BY city ORDER BY city

  ScanOp          ← reads RowGroup, yields Batches
    ↓
  FilterOp        ← narrows selection (age > 30)
    ↓
  GroupByOp       ← hashes by city, runs aggregators
    ↓
  OrderByOp       ← sorts result by city ASC
    ↓
  results

Data Flow

SQL path: Tokenize → Parse → Plan → exec.Operator tree → consumer drains via Next()

Write path: typed Columns + NullBitmap → ColumnChunks → RowGroup → Encoder → LZ4 → bytes on disk

Read path: open file, read footer → decompress + decode → in-memory RowGroup

Component Details

Storage

Column chunks, row groups, null bitmaps, file I/O

Encoding

RLE, dictionary, delta, LZ4 compression

Execution

Vectorized operators, batches of 1024

SQL Frontend

Hand-rolled lexer, parser, planner
